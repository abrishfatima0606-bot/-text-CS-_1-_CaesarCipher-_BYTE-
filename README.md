# Caesar Cipher (Text Encryption/Decryption) - AVIP 2026

## Overview
This Python application implements a Caesar Cipher tool capable of encrypting and decrypting plaintext messages using a configurable shift key. Developed as part of the **Arithmatrix Virtual Internship Program (AVIP 2026)** under the Cybersecurity track.

## Features
- **Configurable Shift Values:** Supports custom integer key shifts.
- **Case Sensitivity:** Preserves uppercase and lowercase letters.
- **Character Preservation:** Keeps spaces, numbers, and special symbols unchanged.
